# خزونة (Khazzouna)

لعبة اختباء وبحث ثلاثية الأبعاد، معبأة كتطبيق أندرويد عبر Capacitor.

## كيف يُبنى ملف APK

لا حاجة لأي إعداد محلي. كل شيء يُبنى تلقائياً عبر GitHub Actions:

1. أي دفع (push) إلى فرع `main` يُشغّل workflow البناء تلقائياً.
2. يمكن أيضاً تشغيله يدوياً من تبويب **Actions** في المستودع (زر "Run workflow").
3. بعد اكتمال البناء، يظهر ملف APK كـ "Artifact" باسم `khazzouna-debug-apk` يمكن تنزيله من صفحة التشغيل (run).

هذا APK **تجريبي (debug)** غير موقّع رسمياً لمتجر Google Play، لكنه صالح للتثبيت اليدوي مباشرة على أي هاتف أندرويد (قد تحتاج لتفعيل "تثبيت من مصادر غير معروفة" في إعدادات الهاتف).
